
# 李祎 · 数智教育个人品牌主页

这是一个基于 **React 19** 和 **Google Gemini 3 Pro** 模型构建的个人品牌主页。

## 🚀 项目特性
- **数智咨询**: 集成 Gemini 3 Pro 模型的 AI 聊天助手。
- **响应式设计**: 完美适配移动端、平板和 PC。
- **现代化技术栈**: 使用 Tailwind CSS 进行样式管理，Lucide React 提供图标。
- **高性能**: 基于 Vite 构建，支持 Vercel 和 Cloudflare 一键部署。

## 🛠️ 技术栈
- **核心**: React 19 + TypeScript
- **AI**: @google/genai (Gemini 3 Pro)
- **构建**: Vite
- **部署**: Vercel / Cloudflare Pages

## 📦 本地开发
1. 克隆项目
2. 安装依赖: `npm install`
3. 配置环境变量: 创建 `.env` 文件并添加 `VITE_API_KEY=你的Gemini密钥`
4. 运行: `npm run dev`

## 🌐 部署说明
本应用已针对 Vercel 和 Cloudflare 进行了优化。
部署时请确保在平台控制面板的 **Environment Variables** 中添加 `API_KEY` 变量。
